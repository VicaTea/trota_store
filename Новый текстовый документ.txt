О моем проекте

«Тише, дорогая Мита» — мультсериал, созданный проектом TROTA. Подходит для подростков и взрослых (16+). 2 источника

Сюжет: девочка-подросток Мита из малого технического городка чувствует себя подавленно и одиноко из-за ссор с отцом. Во время побега её сбивает фургон двух эксцентричных, но добрых актёров, что помогают людям из больших городов решать проблемы при помощи особой методики — куклотерапии. trota-project.ru

Основная идея: Мита узнаёт о прибывшей в её город корпорации бесплатной помощи людям TROTA и решает обратиться туда за помощью. Там ей помогают научиться контролировать её эмоции, в особенности гнев, и учат стратегически относиться к каждой ситуации при помощи кукольной игры. 

Некоторые персонажи мультсериала «Тише, дорогая Мита»:

    Главная героиня — Митаэлла (Мита), 13-летняя девочка, которая каждый день ссорится со своим отцом из-за одинаково непреклонных характеров. planeta.ru
    Владельцы корпорации TROTA — семейный психолог Леммануэль и кукольная актриса Нина. planeta.ru
    Второстепенные персонажи: учитель математики и программирования Дон Григорьев, отец Миты Павел, мама Миты Дина, друзья Миты — лучшая подруга Полина, подруги Камилла, Лёля и друг Вано. planeta.ru
    Персонажи государственной компании Mercy School, которая помогает трудным подросткам влиться в общество. В неё входят воспитательная работница и бизнес-леди Мальвина, а также её лучшая ученица и помощница Аделаида.

Первая серия мультсериала «Тише, дорогая Мита» рассказывает о девочке из технического городка, которая не может найти общий язык со своим отцом. Эти ссоры негативно сказываются не только на ней самой, но и на её учёбе.  2 источника

Всё меняется, когда Мита узнаёт о существовании сказочного театра «Помощи людям», который способен изменить её судьбу.

Вот пример: function generateAndDownloadFile() {
    const formType = document.getElementById('form-type').value;
    const name = document.getElementById('name').value;
    const contact = document.getElementById('contact').value;
    const subject = document.getElementById('subject').value;
    const message = document.getElementById('message').value;
    const jobPosition = document.getElementById('job-position').value;
    const portfolio = document.getElementById('portfolio').value;

    let fileContent = `Тип запроса: ${formType}\n`;
    fileContent += `Имя: ${name}\n`;
    fileContent += `Контакты: ${contact}\n`;

    if (subject) {
        fileContent += `Тема вопроса: ${subject}\n`;
    }

    fileContent += `Сообщение:\n${message}\n`;

    if (formType === 'job') {
        fileContent += `Позиция: ${jobPosition}\n`;
        fileContent += `Портфолио: ${portfolio}\n`;
    }

    const blob = new Blob([fileContent], { type: 'text/plain' });
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = 'vopros.txt';
    document.body.appendChild(a);
    a.click();
    URL.revokeObjectURL(url);
    document.body.removeChild(a);

    document.getElementById('download-instructions').style.display = 'block';
}
